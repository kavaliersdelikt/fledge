# Fledge v0.1.7

## Added

- The Windows PowerShell WSL connector now installs and starts the Linux agent as the `fledge-agent.service` systemd service by default, then returns to PowerShell. Use `-Foreground` for temporary interactive runs.
- Added WSL systemd setup, service management, and Linux password guidance to the node installation documentation.

## Fixed

- Made the Windows installer health checks compatible with Windows PowerShell 5.1, avoiding the unavailable `System.Net.Http.HttpClientHandler` type.
- Clarified connector errors when WSL systemd is missing or not running.
- Fixed the one-click updater failing on Windows checkouts with CRLF line endings; shell scripts now retain LF endings, and the updater normalizes the script before running it.

## Notes

- Background service mode in WSL requires systemd enabled in `/etc/wsl.conf` and Docker Desktop WSL Integration enabled for the selected distro.
