# Fledge v0.1.5

## Fixed

- Honor the explicit `--allow-insecure-http` opt-in during node enrollment. Previously the connector allowed HTTP for its initial API checks but forced HTTPS for the enrollment request, so local HTTP installations could not complete enrollment.

## Verified

- Ran the first-run installer against a disposable Docker Compose environment with Docker Desktop WSL integration enabled.
- Confirmed the API and panel became ready and the panel returned HTTP 200.
- Enrolled a disposable Linux node against the local HTTP API using the explicit insecure-HTTP option. The connector downloaded the published agent and checksum, validated the checksum, accepted enrollment, and launched the agent.
