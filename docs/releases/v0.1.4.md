# Fledge v0.1.4 — Pre-release

This release improves first-time installation and Windows/WSL node setup.

## Highlights

- Allow slow first-time Docker builds up to five minutes for the API and panel to become reachable before reporting a startup timeout.
- Fix Windows PowerShell-to-Bash line ending handling in the WSL agent build and connector helpers.
- Clarify Linux agent requirements, explain why native Windows `go build` fails, and document Docker Desktop WSL Integration before connecting a node.
- Align API, web, agent, installer defaults, and release metadata on version 0.1.4.

## Verification

- Fresh isolated Docker Compose install generated a new `.env`, built the API, updater, and panel, started all five services, and reported healthy PostgreSQL, API (`/api/health`), and panel (HTTP 200).
- Re-running the installer reused the existing `.env` without modifying it.
- Linux/amd64 agent build succeeded from Windows PowerShell through WSL.
- PowerShell connector argument validation and Bash line-ending handling were checked. Full node enrollment was not completed because Docker Desktop WSL Integration is disabled for the test distro; enable it before connecting.

## Notes

- Native Windows is not a supported agent target. Use a supported Linux host or WSL2 for local evaluation.
- The agent requires Docker Engine and the Docker CLI to be available inside its Linux distro before enrollment.
- This is an evaluation pre-release; validate backups, recovery, networking, and upgrades in your target environment.
