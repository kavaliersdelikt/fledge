# Changelog

## 1.0.0

- First release: a **Rich embed** and a **Compact embed** style for Discord notification channels, for administrators and customers.
- Colour by severity (changeable), an emoji per event, the server, the cause of a crash, facts from the event, the last console lines, a link to the panel and a footer with the event code.
- Optional sender name and picture, and an optional role ping on the administrators' channels only.
